# 0.7.1 release inventory

The GitHub ZIP contains the files listed in RELEASE-MANIFEST.txt. SHA256SUMS
checks every payload file except itself. Both ARM64 Mac MEX binaries and the
local Python 3.14 extension are included with their source, tests and demos.
The phone payload includes source, static art, icons, offline documents, build
configuration and App Store preparation files.

Generated Xcode projects/apps, build objects, caches, egg-info, measurement logs,
and local signing material are excluded without deleting the local development
copies. The iOS device/simulator Python 3.14 wheels are separate release assets;
download them into phone/wheels for Briefcase. Mac Python wheels and source
packages are generated by the repository's existing tagged-release workflow.
